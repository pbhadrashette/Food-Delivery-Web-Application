# 🍔 Food Delivery Web Application

## 📌 About the Project

Food Delivery Web Application is a full-stack web application developed using the MERN Stack. It allows users to browse food items, explore menus, add products to their cart, and place food orders online.

The application provides a user-friendly interface and a convenient online food ordering experience.

## 🚀 Features

- User Registration and Login
- Browse Food Items
- Search Food Items
- Add to Cart
- Place Food Orders
- Responsive User Interface
- Backend API Integration
- MongoDB Database Connectivity
- Admin Dashboard (if implemented)

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/pbhadrashette/Food-Delivery-Web-Application.git
```

### 2. Navigate to Project Folder

```bash
cd Food-Delivery-Web-Application
```

### 3. Setup Backend

```bash
cd backend
npm install
```

Create a `.env` file using `.env.example` and configure your MongoDB connection string and other required environment variables.

Start the backend:

```bash
npm run dev
```

### 4. Setup Frontend

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```

### 5. Open Application

Open the local URL displayed by Vite in your browser.

## 🔐 Environment Variables

Configure the required environment variables in the backend `.env` file.

Never upload your actual `.env` file or database credentials to GitHub.
